# SiK UI Framework 1.0.6

## Fixes

- Escape literal percentages in the opacity tooltip across all ten supported
  translations for Project Zomboid 42.21's formatted translation path.
  The visible wording is preserved.
- Align runtime version and mod metadata at 1.0.6.

## Compatibility and validation

Minimum build remains 42.20. Technical compatibility was reviewed against 42.21.
The ten original strings reproduce Java formatting exceptions; the corrected
strings format to the original visible wording. Lua/Kahlua and development
contracts passed. These are not proof of PZ rendering, split-screen or every
consumer's runtime behavior.

This companion release does not itself implement the multiplayer proposals in
[Global Storage Issue #1](https://github.com/Kavalieri/GlobalStorageSiK/issues/1).
